## Séance 1 — 2026-07-01 : Développement et Factorisation

### Cours : Développement et Factorisation

#### 1. Le développement
Développer une expression littérale consiste à transformer un produit en une somme ou une différence.
- Distributivité simple : a * (b + c) = a * b + a * c
- Double distributivité : (a + b) * (c + d) = a * c + a * d + b * c + b * d

Exemple :
Développer 3 * (x + 2) = 3x + 6.
Développer (x + 2) * (x + 5) = x² + 5x + 2x + 10 = x² + 7x + 10.

#### 2. La factorisation
Factoriser consiste à transformer une somme ou une différence en un produit de facteurs. C'est l'inverse du développement.
- Recherche d'un facteur commun : a * b + a * c = a * (b + c)

Exemple :
Factoriser 5x + 15 = 5 * (x + 3).

## Séance 2 — 2026-07-08 : Équations du premier degré

### Cours : Équations du premier degré

#### 1. Définition et règles de base
Une équation est une égalité contenant une ou plusieurs inconnues (souvent notées x). Résoudre une équation, c'est trouver la ou les valeurs de x pour lesquelles l'égalité est vraie.
Pour résoudre une équation du premier degré, on utilise les règles suivantes :
- On peut ajouter ou soustraire un même nombre aux deux membres d'une égalité.
- On peut multiplier ou diviser par un même nombre non nul les deux membres d'une égalité.

Exemple :
Résoudre 3x - 5 = 7 :
3x = 7 + 5
3x = 12
x = 12 / 3 = 4.
La solution est 4.

#### 2. Mise en équation d'un problème
- Étape 1 : Choisir l'inconnue (soit x la quantité recherchée).
- Étape 2 : Traduire l'énoncé par une équation.
- Étape 3 : Résoudre l'équation.
- Étape 4 : Conclure en interprétant le résultat.

## Séance 3 — 2026-07-15 : Équations-produits nuls

### Cours : Équations-produits nuls

#### 1. Théorème du produit nul
Un produit de facteurs est nul si, et seulement si, l'un au moins des facteurs est nul.
Soit l'équation : A * B = 0.
Cette équation équivaut à : A = 0 ou B = 0.

#### 2. Méthode de résolution
Pour résoudre une équation de la forme (ax + b) * (cx + d) = 0 :
- Étape 1 : On pose ax + b = 0 ou cx + d = 0.
- Étape 2 : On résout séparément ces deux équations du premier degré.
- Étape 3 : On liste les deux solutions obtenues.

Exemple :
Résoudre (2x - 4) * (3x + 9) = 0 :
2x - 4 = 0 => 2x = 4 => x = 2
ou
3x + 9 = 0 => 3x = -9 => x = -3.
Les solutions sont -3 et 2.
