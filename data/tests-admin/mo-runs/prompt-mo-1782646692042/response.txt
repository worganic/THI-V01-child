# 🏡 Projet d'Acquisition et de Création d'une Maison d'Hôtes

Ce document présente le plan de cadrage opérationnel, financier et immobilier pour le projet d'achat d'un bien immobilier et sa transformation en maison d'hôtes. En tant qu'expert immobilier et comptable, j'ai structuré ce projet pour maximiser la rentabilité et minimiser les risques d'acquisition.

## 📌 Présentation du Projet
L'objectif est d'acquérir une propriété de caractère avec un potentiel de 4 à 5 chambres d'hôtes, idéalement située dans une zone touristique à fort potentiel. Le projet intègre une phase d'audit immobilier, de montage financier (business plan), de réalisation des travaux de mise aux normes ERP (Établissement Recevant du Public), et de lancement commercial.

## 🚦 Décisions de Validation et Points de Vigilance

Avant de s'engager définitivement sur l'acquisition d'un bien, cette grille de décision doit être impérativement complétée.

```FORM: Grille d'évaluation du bien
* **Le bien répond-il aux critères d'emplacement géographique ?**
  * ( ) Oui, parfait (attractivité touristique élevée, commodités à proximité)
  * ( ) Moyen (calme mais nécessite un véhicule pour toute activité)
  * ( ) Non conforme (trop éloigné des points d'intérêt)
* **Les travaux de mise en conformité sécurité et accessibilité (ERP) sont-ils chiffrés ?**
  * ( ) Oui, intégrés dans les devis et validés
  * ( ) En cours d'évaluation par le maître d'œuvre
  * ( ) Non chiffrés (risque financier élevé)
* **Le diagnostic technique immobilier présente-t-il des anomalies majeures (amiante, plomb, structure) ?**
  * ( ) Aucun problème majeur identifié
  * ( ) Problèmes identifiés mais chiffrés et négociables
  * ( ) Anomalies graves (à rejeter ou renégociation totale)
* **Le modèle économique est-il viable (seuil de rentabilité atteignable avec un taux d'occupation de 40%) ?**
  * ( ) Oui, le point mort est bas
  * ( ) Limite, nécessite des tarifs élevés
  * ( ) Non viable en l'état
```
