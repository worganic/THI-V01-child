## Séance 1 — 2026-06-29 : Les quatre opérations et le sens des calculs

### Contenu du cours
Pour bien maîtriser les mathématiques, il faut comprendre le sens des opérations que l'on effectue et être très rigoureux dans leur écriture.

1. **L'addition** : On l'utilise pour regrouper ou ajouter des quantités.
   - *Exemple* : Si j'ai 12 billes et que j'en gagne 15, j'en ai maintenant 12 + 15 = 27.
2. **La soustraction** : On l'utilise pour enlever une quantité ou pour chercher une différence (un écart).
   - *Exemple* : Si j'ai 27 billes et que j'en perds 12, il m'en reste 27 - 12 = 15.
3. **La multiplication** : On l'utilise pour répéter plusieurs fois la même quantité.
   - *Exemple* : Si j'achète 4 paquets de 5 bonbons, j'ai 4 * 5 = 20 bonbons en tout.
4. **La division** : On l'utilise pour partager équitablement une quantité en plusieurs parts égales, ou pour chercher combien de fois une quantité est contenue dans une autre.
   - *Exemple* : Si je partage 20 bonbons entre 4 enfants, chacun aura 20 / 4 = 5 bonbons.

### Rigueur de rédaction
- Écris toujours ton opération en ligne (par exemple : 143 - 87 = ...) avant de la poser en colonne.
- En colonne, aligne parfaitement les unités sous les unités, les dizaines sous les dizaines, etc.
- Note soigneusement les retenues en haut et entoure-les pour ne pas les oublier.
- Souligne tes traits à la règle.

```FORM: QCM Séance 1
* **Question 1 : Si j'ai 5 paquets de 6 bonbons, quelle opération modélise cette situation ?**
  * ( ) 5 + 6
  * ( ) 6 - 5
  * ( ) 5 * 6
  * ( ) 30 / 5
* **Question 2 : Dans la soustraction posée 143 - 87, combien vaut le chiffre des dizaines du résultat ?**
  * ( ) 4
  * ( ) 5
  * ( ) 6
* **Question 3 : Une classe de 24 élèves est répartie en équipes de 4. Quelle opération permet de trouver le nombre d'équipes ?**
  * ( ) 24 - 4
  * ( ) 24 / 4
  * ( ) 24 * 4
* **Question 4 : Cochez les affirmations qui sont correctes concernant la division de 17 par 5 :**
  * [ ] Le quotient entier est 3
  * [ ] Le reste est 2
  * [ ] Le reste est supérieur au diviseur
```

## Séance 2 — 2026-07-06 : Résolution de problèmes et schématisation

### Contenu du cours
Résoudre un problème, ce n'est pas seulement trouver le bon résultat, c'est aussi expliquer clairement son raisonnement.

### Méthode pas à pas
1. **Lire l'énoncé** : Repère la question et surligne les mots importants (total, reste, chacun, partager...).
2. **Schématiser** : Dessine un schéma (par exemple, un schéma en barres) pour représenter la situation. Cela évite de se tromper d'opération.
3. **Écrire le calcul en ligne** : Justifie ton choix d'opération.
4. **Poser le calcul** : Effectue l'opération proprement.
5. **Rédiger la phrase réponse** : Réponds à la question posée par une phrase complète qui contient l'unité (euros, bonbons, kilomètres...).

```FORM: QCM Séance 2
* **Question 1 : Tom a 15 billes. Il en donne 6 à Léo. Quelle représentation en barre est correcte ?**
  * ( ) Une barre totale de 15 divisée en deux parties : une partie de 6 et une partie inconnue.
  * ( ) Deux barres indépendantes de 15 et 6 pour trouver le total de 21.
* **Question 2 : Cochez les éléments indispensables pour la rédaction d'un problème :**
  * [ ] Le schéma ou dessin explicatif
  * [ ] L'opération en ligne avec justification
  * [ ] Le calcul posé
  * [ ] La phrase réponse complète avec l'unité
* **Question 3 : "Un libraire vend 3 livres à 8 € chacun et un cahier à 4 €." Quel calcul permet de trouver le prix total ?**
  * ( ) 3 * 8 * 4
  * ( ) (3 * 8) + 4
  * ( ) 3 + 8 + 4
* **Question 4 : Si un problème demande combien de bonbons il reste après avoir fait des paquets égaux, quel calcul doit-on faire ?**
  * ( ) Une soustraction simple
  * ( ) Une division pour trouver le reste
  * ( ) Une multiplication
```

## Séance 3 — 2026-07-13 : Les fractions et le partage

### Contenu du cours
Une fraction sert à représenter le partage d'une unité en parts égales.

1. **Vocabulaire** : Dans la fraction 3/4 (trois quarts) :
   - Le chiffre du bas (4) est le **dénominateur**. Il indique en combien de parts égales l'unité a été coupée.
   - Le chiffre du haut (3) est le **numérateur**. Il indique combien de parts on prend.
2. **Représentation** : Pour dessiner 3/4, on trace un rectangle, on le coupe en 4 parts parfaitement identiques, et on en colorie 3.
3. **Fractions égales** : Si on coupe chaque part en deux, on obtient 6/8, ce qui représente la même quantité que 3/4. Donc 3/4 = 6/8.

```FORM: QCM Séance 3
* **Question 1 : Dans la fraction 2/5, que représente le nombre 5 ?**
  * ( ) Le nombre de parts que l'on prend
  * ( ) Le nombre total de parts égales qui coupent l'unité
  * ( ) Le résultat du calcul
* **Question 2 : Quelle fraction est égale à 1/2 ?**
  * ( ) 2/3
  * ( ) 4/8
  * ( ) 3/5
* **Question 3 : Cochez les fractions qui sont strictement plus grandes que 1 :**
  * [ ] 4/3
  * [ ] 2/2
  * [ ] 7/5
  * [ ] 1/3
* **Question 4 : J'ai mangé les 2/6 d'un gâteau. Quelle fraction de gâteau reste-t-il ?**
  * ( ) 4/6

  * ( ) 6/6
```

## Séance 4 — 2026-07-20 : Priorités opératoires et écriture des calculs

### Contenu du cours
Quand une expression contient plusieurs opérations, il y a des règles précises pour savoir par quoi commencer.

1. **Les parenthèses** : Les calculs entre parenthèses `( )` sont toujours prioritaires.
2. **La multiplication et la division** : Elles sont prioritaires sur l'addition et la soustraction.
3. **De gauche à droite** : Si les opérations ont la même priorité, on calcule dans l'ordre de lecture.

### Rigueur de rédaction
Pour calculer une longue expression, on réécrit toute l'expression à chaque étape en alignant les signes `=`.
*Exemple* :
A = 5 + 3 * 4
A = 5 + 12 (la multiplication est prioritaire !)
A = 17

```FORM: QCM Séance 4
  * ( ) 60
  * ( ) 20
  * ( ) 50
* **Question 3 : Cochez les étapes correctes pour calculer A = 20 - 6 / 2 :**
  * [ ] A = 20 - 3
  * [ ] A = 14 / 2
  * [ ] A = 17
* **Question 4 : Quelle expression correspond à "ajouter 4 au produit de 3 par 5" ?**

  * ( ) 4 * 3 + 5
```
