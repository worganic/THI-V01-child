## Séance 2 — 2026-07-06 : Calcul numérique et fractions

### Contenu du cours
Les fractions expriment un partage ou un rapport entre deux nombres entiers. Pour les manipuler efficacement :
- Addition et soustraction : Mettez les fractions au même dénominateur avant d'additionner ou soustraire leurs numérateurs. Exemple : 1/4 + 2/3 = 3/12 + 8/12 = 11/12.
- Multiplication : Multipliez les numérateurs entre eux et les dénominateurs entre eux. Exemple : (2/3) * (5/7) = 10/21.
- Division : Diviser par une fraction revient à multiplier par son inverse. Exemple : (3/4) / (2/5) = (3/4) * (5/2) = 15/8.

### Exercices d'application
```FORM: QCM Séance 2
* **Question 1 : Calculez la somme : 3/4 + 1/2. Quelle est la fraction simplifiée ?**
  * ( ) 4/6
  * ( ) 5/4
  * ( ) 1/2
* **Question 2 : Calculez le produit : 2/3 * 9/4. Quelle est la valeur simplifiée ?**
  * ( ) 3/2
  * ( ) 18/12
  * ( ) 11/7
* **Question 3 : Calculez la division : (2/5) / (3/10). Quel est le résultat ?**
  * ( ) 4/3
```

## Séance 3 — 2026-07-13 : Équations du premier degré

### Contenu du cours
Une équation du premier degré à une inconnue est une égalité contenant une variable (souvent notée x). Résoudre l'équation consiste à trouver la valeur de x qui rend l'égalité vraie.
Méthode de résolution :
1. Regroupez les termes en x d'un côté de l'égalité et les nombres constants de l'autre.
2. Si vous déplacez un terme d'un côté à l'autre, son signe change (un plus devient moins, et inversement).
3. Divisez enfin par le coefficient devant x.
Exemple : 3x - 4 = 11 => 3x = 11 + 4 => 3x = 15 => x = 15 / 3 = 5.

### Exercices d'application
```FORM: QCM Séance 3
* **Question 1 : Résolvez l'équation 4x - 7 = 5. Quelle est la valeur de x ?**
  * ( ) x = 3
  * ( ) x = -3
  * ( ) x = 0.5
* **Question 2 : Résolvez l'équation 2x + 8 = -2. Quelle est la valeur de x ?**
  * ( ) x = 5
  * ( ) x = -5
  * ( ) x = -3
* **Question 3 : Résolvez l'équation 3(x - 2) = 12. Quelle est la valeur de x ?**
  * ( ) x = 6
  * ( ) x = 4
  * ( ) x = 2
```
