## Séance 1 — 2026-07-01 : Les bases du calcul algébrique

### 1. Rappels sur les fractions
Pour additionner ou soustraire deux fractions, on les met au même dénominateur :
a/b + c/d = (ad + bc)/(bd)

Pour multiplier deux fractions, on multiplie les numérateurs entre eux et les dénominateurs entre eux :
(a/b) * (c/d) = (ac)/(bd)

Pour diviser par une fraction, on multiplie par son inverse :
(a/b) / (c/d) = (a/b) * (d/c) = (ad)/(bc)

### 2. Les puissances
Soit a un nombre réel non nul et n, m deux entiers relatifs :
- a^n * a^m = a^(n+m)
- (a^n)^m = a^(n*m)
- a^n / a^m = a^(n-m)
- a^(-n) = 1 / a^n

### 3. Le développement
Développer, c'est transformer un produit en une somme.
- Simple distributivité : k(a + b) = ka + kb
- Double distributivité : (a + b)(c + d) = ac + ad + bc + bd
- Identités remarquables (indispensables au lycée) :
  - (a + b)^2 = a^2 + 2ab + b^2
  - (a - b)^2 = a^2 - 2ab + b^2
  - (a - b)(a + b) = a^2 - b^2

## Séance 2 — 2026-07-08 : Équations et inéquations du premier degré

### 1. Équations du premier degré
Une équation du premier degré se présente sous la forme ax + b = c.
Pour la résoudre :
1. On isole le terme en x d'un côté de l'égalité : ax = c - b.
2. On divise par a (si a est non nul) : x = (c - b)/a.

### 2. Équations-produits
Un produit de facteurs est nul si et seulement si l'un au moins des facteurs est nul.
A(x) * B(x) = 0 équivaut à A(x) = 0 ou B(x) = 0.
Exemple : (x - 3)(2x + 4) = 0 <=> x - 3 = 0 ou 2x + 4 = 0 <=> x = 3 ou x = -2.

### 3. Inéquations du premier degré
La méthode de résolution est similaire à celle des équations, à une règle fondamentale près :
Si l'on multiplie ou divise les deux membres d'une inéquation par un nombre négatif, on doit changer le sens de l'inégalité.
Exemple : -3x > 6 <=> x < 6 / (-3) <=> x < -2.

## Séance 3 — 2026-07-15 : Introduction et généralités sur les fonctions

### 1. Notion de fonction
Une fonction f associe à chaque nombre x d'un ensemble de définition D un unique nombre réel noté f(x).
- x est la variable, c'est l'antécédent.
- f(x) est l'image de x par f.

### 2. Détermination par le calcul et graphiquement
- Par le calcul : pour trouver l'image de 3 par f(x) = x^2 - 1, on calcule f(3) = 3^2 - 1 = 8. Pour trouver les antécédents de 3, on résout f(x) = 3 <=> x^2 - 1 = 3.
- Graphiquement :
  - L'image de a est l'ordonnée du point de la courbe d'abscisse a.
  - Les antécédents de b sont les abscisses des points d'intersection de la courbe avec la droite horizontale y = b.

### 3. Variations et extremums
- Une fonction f est croissante sur un intervalle si elle conserve l'ordre des nombes : si u < v, alors f(u) < f(v).
- Une fonction f est décroissante sur un intervalle si elle inverse l'ordre des nombres : si u < v, alors f(u) > f(v).
- Le maximum de f sur un intervalle est la plus grande valeur atteinte par f(x). Le minimum est la plus petite.

## Séance 4 — 2026-07-22 : Fonctions de référence et second degré

### 1. Les fonctions de référence
- Fonction carré (f(x) = x^2) : définie sur R, décroissante sur les réels négatifs et croissante sur les réels positifs. Elle est toujours positive.
- Fonction inverse (f(x) = 1/x) : définie sur R* (c'est-à-dire R privé de 0). Elle est strictement décroissante sur les nombres négatifs, et strictement décroissante sur les nombres positifs.

### 2. Résolution d'équations du second degré simples
L'équation x^2 = k admet :
- Deux solutions si k > 0 : x = racine(k) ou x = -racine(k).
- Une solution si k = 0 : x = 0.
- Aucune solution réelle si k < 0.

### 3. Signe d'une expression factorisée du second degré
Pour étudier le signe d'un produit comme (x - a)(x - b), on dresse un tableau de signes combinant le signe de chaque facteur linéaire.
