## 🔍 Validation et Critères de Choix du Bien

Lors des visites de biens, ce questionnaire sert de grille de validation comptable et technique pour décider ou non d'une offre d'achat.

```FORM: Grille de Décision Bien
* **Le coût total (achat + frais + travaux estimés) reste-t-il sous l'enveloppe des 300 000 € ?**
  * ( ) Oui, le prix d'achat et le devis estimatif de rénovation entrent dans le budget
  * ( ) Non, le coût global présente un risque de dépassement important
* **Le bien est-il techniquement adaptable aux exigences de sécurité incendie ERP (5e catégorie) ?**
  * ( ) Oui, les issues, la structure et les dégagements permettent une mise aux normes aisée
  * ( ) Non, la structure rend les travaux de sécurité trop complexes ou coûteux
* **La capacité d'accueil permet-elle d'aménager au moins 3 à 5 chambres d'hôtes ?**
  * ( ) Oui, la surface habitable et la disposition actuelle ou projetée s'y prêtent parfaitement
  * ( ) Non, la capacité de création de chambres est trop restreinte
* **La localisation géographique du bien présente-t-elle un intérêt touristique ou d'affaires ?**
  * ( ) Oui, forte zone touristique, proximité d'axes majeurs ou de commodités
  * ( ) Non, zone isolée à faible flux de visiteurs
* **Le rendement locatif prévisionnel basé sur le taux d'occupation cible (45%) couvre-t-il les échéances d'emprunt ?**
  * ( ) Oui, le cash-flow prévisionnel est positif
  * ( ) Non, le projet nécessite un apport personnel ou un autofinancement permanent
```
