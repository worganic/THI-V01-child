## Plan de Travail Personnalisé

Voici le planning type proposé pour structurer votre progression et valider chaque étape de votre apprentissage.

```TRELLO: Plan de formation
### À faire
- [ ] Évaluation diagnostique initiale `[high]`
  Passer le test de positionnement pour identifier les lacunes.
- [ ] Chapitre 1 : Rappels de cours et notions de base `[medium]`
  Lire les fiches de cours et visionner les vidéos explicatives.
- [ ] Chapitre 2 : Approfondissement et applications directes `[medium]`
  Faire les premiers exercices d'application.
### En cours
- [ ] Sessions de tutorat individuel `[critical]`
  Clarifier les points de blocage avec le formateur.
### Terminé
- [ ] Constitution du dossier d'inscription `[low]`
  Finalisation des démarches administratives.
```

## Exercices de Validation des Acquis

Veuillez répondre à ces questions pour valider votre compréhension des premières notions clés.

```FORM: Evaluation
* **Quelle est la valeur de x pour l'équation 3x - 7 = 5 ?**
  * [ ] x = 2
  * [ ] x = 4
  * [ ] x = -4
  * [ ] x = 12

* **Quelle est la dérivée de la fonction f(x) = x² + 3x ?**
  * [ ] f'(x) = 2x
  * [ ] f'(x) = 2x + 3
  * [ ] f'(x) = x + 3
  * [ ] f'(x) = 3x²
```
