## 📝 Formulaire de Décision pour l'Achat du Bien

Ce questionnaire doit être rempli après chaque visite afin de déterminer de manière objective s'il convient de formuler une offre d'achat.

```FORM: Évaluation de Propriété
* **1. Le nombre de chambres potentielles est-il conforme au projet (minimum 4 chambres d'hôtes) ?**
  * ( ) Oui, directement exploitable
  * ( ) Oui, moyennant des travaux d'aménagement intérieur
  * ( ) Non, espace insuffisant pour l'activité visée
* **2. L'emplacement présente-t-il une attractivité touristique forte ?**
  * ( ) Excellente (proche d'un grand site touristique ou axe majeur)
  * ( ) Moyenne (secteur calme mais accessible)
  * ( ) Insuffisante (trop éloigné des points d'intérêt)
* **3. Quel est l'état général du gros œuvre et de la toiture ?**
  * [ ] Très bon état, aucun travaux structurels à prévoir
  * [ ] Travaux de rénovation énergétique nécessaires (isolation, chauffage)
  * [ ] Travaux importants de toiture ou de maçonnerie à prévoir
* **4. Le bien dispose-t-il d'un espace extérieur exploitable pour les clients (jardin, terrasse, piscine) ?**
  * ( ) Oui, grand jardin avec terrasse aménagée
  * ( ) Oui, petit espace extérieur à aménager
  * ( ) Non, aucun espace extérieur disponible
* **5. Décision proposée à l'issue de la visite :**
  * ( ) Faire une offre d'achat au prix ou négociée
  * ( ) Planifier une contre-visite technique avec un expert ou un artisan
  * ( ) Ne pas donner suite (le bien ne correspond pas aux critères clés)
```
