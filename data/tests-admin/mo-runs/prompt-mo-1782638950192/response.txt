# Projet d'Acquisition Immobilière - Création d'une Maison d'Hôtes

## 📋 Présentation du Projet
Ce document regroupe les outils de pilotage, de planification et de suivi pour l'achat d'un bien immobilier destiné à être transformé en maison d'hôtes. Il couvre les étapes de définition du besoin, de recherche, d'analyse financière, d'acquisition et de lancement des travaux.

### 6. Validation Critère d'Achat (Formulaire)
Ce formulaire aide à valider la conformité d'un bien visité par rapport aux besoins du projet avant de formuler une offre d'achat.

```FORM: Validation
* **Le bien répond-il aux critères géographiques et d'accessibilité ?**
  * ( ) Oui, parfait emplacement (calme, accessible, proche attractions)
  * ( ) Moyennement (quelques nuisances ou accès difficile en hiver)
  * ( ) Non, à exclure
* **Quel est l'état technique général du bâtiment (toiture, gros œuvre) ?**
  * ( ) Excellent état, aucun gros œuvre à prévoir
  * ( ) Bon état général, rafraîchissement nécessaire
  * ( ) Gros travaux structurels à prévoir (toiture, assainissement non conforme)
* **La disposition permet-elle de créer au moins 4 à 5 chambres d'hôtes indépendantes ?**
  * ( ) Oui, la configuration actuelle s'y prête directement
  * ( ) Oui, mais moyennant des travaux de redistribution des pièces
  * ( ) Non, la structure ne permet pas d'avoir suffisamment de chambres indépendantes
* **La capacité financière estimée est-elle respectée ?**
  * ( ) Oui, le prix est en dessous ou égal au budget max
  * ( ) Limite, nécessite une négociation serrée
  * ( ) Hors budget
* **Y a-t-il un espace extérieur exploitable (jardin, terrasse, piscine) ?**
  * [ ] Grand jardin arboré
  * [ ] Piscine ou possibilité d'en construire une
  * [ ] Terrasse exploitable pour les petits-déjeuners
  * [ ] Aucun espace extérieur
```
