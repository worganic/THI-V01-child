# Guide d'Achat Immobilier pour la Création d'une Maison d'Hôtes

Ce document constitue le livrable complet pour vous accompagner pas à pas dans l'acquisition de votre futur bien immobilier destiné à être exploité en maison d'hôtes. Il intègre tous les outils nécessaires au suivi de votre projet, de la définition de votre budget jusqu'au lancement commercial.

## 3. Exercices d'évaluation des compétences

Validez vos acquis à chaque étape clé grâce à ces questionnaires interactifs.

```FORM: Exercices Projet et Budget
* **Quelle est votre capacité d'apport personnel minimum recommandée pour un projet de maison d'hôte ?**
  * ( ) 5% du projet global
  * ( ) 10% du projet global
  * ( ) 20% à 30% du projet global pour couvrir le besoin en fonds de roulement et les frais annexes
  * ( ) Aucune importance, les banques financent à 110%
* **Quel statut juridique est le plus adapté pour une double activité d'hébergement et de table d'hôtes ?**
  * [ ] SARL / EURL
  * [ ] Micro-entreprise (avec plafonds de chiffre d'affaires)
  * [ ] SASU / SAS
* **Comment calculez-vous le chiffre d'affaires prévisionnel annuel ?**
  * ( ) Nombre de chambres x Prix moyen de la nuitée x Taux d'occupation estimé x 365 jours
  * ( ) Estimation libre selon les envies
```

```FORM: Exercices Viabilite ERP
* **À partir de quelle capacité d'accueil en chambres d'hôtes le bien est-il classifié comme ERP (Établissement Recevant du Public) ?**
  * ( ) Plus de 5 chambres et 15 personnes
  * ( ) Plus de 10 chambres
  * ( ) Toutes les maisons d'hôtes sont des ERP
* **Quelle norme d'accessibilité est obligatoire pour une maison d'hôte de moins de 5 chambres ?**
  * ( ) Accessibilité PMR sur toutes les chambres
  * ( ) Aucune obligation d'accessibilité PMR (sauf si création de locaux neufs par changement de destination)
  * ( ) Ascenseur obligatoire
```

## 5. Gestion des tâches et avancement opérationnel

```TRELLO: Avancement
### À faire
- [ ] Préparer les visites de biens `[high]`
  Rechercher des annonces cibles et contacter les agences immobilières
- [ ] Rédiger l'étude de marché locale `[medium]`
  Analyser la concurrence dans un rayon de 20 km
- [ ] Monter le prévisionnel financier `[critical]`
  Détailler les coûts des travaux et d'acquisition
### En cours
- [ ] Valider la capacité de financement `[critical]`
  Contacter le courtier ou la banque avec les premiers chiffres du projet
### Terminé
- [ ] Définir le cahier des charges de la maison d'hôte `[low]`
  Nombre de chambres, localisation, extérieur requis
```
